# 🏡 Real Estate Sales Dashboard

Power BI dashboard for visualizing real estate data, including property types, locations, and furnishing status. Features interactive slicers and summary cards for total properties, area, and price—designed to support dynamic exploration and data-driven insights.

## 📊 Dashboard Highlights
- Property location by furnishing type
- Property type distribution
- Property type by location
- Summary cards: total properties, area, and price

## ✨ Features
- Interactive dashboard built with Power BI
- Visuals for property type, location, and furnishing status
- Summary cards for total properties, area, and price
- Slicers for dynamic filtering

## 🛠️ Installation / Usage
To view the dashboard:
- Install [Power BI Desktop](https://powerbi.microsoft.com/)
- Open the `.pbix` file included in the repository

To explore the dataset:
- Open the `.csv` file using any spreadsheet application

## 📂 Data Source
The dataset was originally downloaded from Kaggle and cleaned for analysis.
